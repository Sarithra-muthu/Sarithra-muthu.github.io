Integration API test execution assistant

Test automation

Problem

On a large enterprise integration programme, analysing API test results meant manually comparing responses, hunting discrepancies, and cross-referencing past defects. Slow, repetitive, and error-prone at scale.

Approach

An LLM-powered assistant that ingests API execution results, flags discrepancies against expected behaviour, and links anomalies to historical defect patterns. E-invoice compliance validator

Data validation · HITL

Problem

E-invoicing rollouts in Europe carry legal compliance risk: XML files must satisfy schema rules, mapping specifications and country regulations. Manual validation is slow and misses subtle mapping errors.

Approach

An LLM validator that checks e-invoice XML against solution designs and best-practice rules, separates data issues from mapping issues, and outputs structured defect reports with severity ratings and owner assignment. Built as a conversation rather than a one-shot report, so the human expert interrogates every finding.

what makes it work

How I work

LLM output alone isn't quality engineering. My agents are designed around expert judgment, and that's the difference between a demo and something a delivery team trusts.

Human-in-the-loop by design

Every agent is a conversation between the model and a domain expert. The LLM drafts and detects; the human challenges, corrects and approves. Iteration is the product.

LLM-as-a-Judge evaluation

Agent output is evaluated systematically for consistency, hallucination and bias before anything reaches a delivery decision.

RAG grounded in real docs

Agents answer from actual requirement documents, schemas and knowledge bases, with citations, rather than from model memory.

AI cost governance

Right model for the right task: lightweight tiers for structured generation, reasoning tiers for analysis. Prompt trimming and context management as standard practice.

Code where it counts

Working knowledge of Python and SQL, enough to build, automate, query data and read what the model writes. Deepening daily through an applied GenAI engineering programme.
